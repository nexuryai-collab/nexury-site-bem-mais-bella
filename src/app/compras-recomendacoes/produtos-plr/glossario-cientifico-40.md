# GLOSSÁRIO CIENTÍFICO 40+ — BASE DE EVIDÊNCIAS

## Princípio editorial

Cada afirmação importante neste glossário é acompanhada de:
- Fonte verificável (DOI, PubMed, diretriz oficial)
- Nível de evidência (forte / moderado / limitado / inconclusivo)
- Limitação do estudo
- Aplicação educacional (o que podemos dizer; o que não podemos prometer)

**Regra:** Se não há evidência suficiente, não afirmamos como fato.

## Glossário dos termos usados na matriz

- **N** = número aproximado de participantes nos estudos analisados (quando agregado em meta-análise/revisão).
- **Desenho** = tipo de estudo: RCT (ensaio clínico randomizado), coorte (observacional longitudinal), revisão sistemática, meta-análise.
- **Intervenção** = o que foi testado (ex: terapia hormonal, exercício, suplemento, TCC, dieta).
- **Controle** = comparador (placebo, sem intervenção, outra intervenção, controle habitual).
- **Resultado** = desfecho principal (sintomas vasomotores, sono, cognição, densidade óssea, etc.).
- **Magnitude** = tamanho do efeito quando disponível / relevante (não é sempre aplicável).
- **Nível de evidência**: 🟢 Forte = múltiplos RCTs consistentes, meta-análise de alta qualidade, diretrizes baseadas; 🟡 Moderado = evidência promissora, mas limitações metodológicas, heterogeneidade, necessidade de mais estudos; 🟠 Limitado = poucos estudos, resultados conflitantes, amostras pequenas, necessidade de confirmação; 🔴 Insuficiente = sem evidência adequada para afirmar; ⚪ Uso tradicional = prática cultural/tradicional sem evidência científica robusta.
- **Fonte verificada** = referência concreta: diretriz (NICE NG23 2026 / OMS / ACOG / The Menopause Society), revisão (Cochrane / BMJ / PubMed), meta-análise (2024-2025), RCT individual (quando mencionado explicitamente).

## Declaração de uso deste glossário

Este glossário não é um diagnóstico. Não substitui consulta médica. Não recomenda nenhuma intervenção específica. Serve para:
- Educativo: compreender o que a ciência sabe e não sabe.
- Preparatório: ajudar a leitora a fazer perguntas informadas ao profissional de saúde.
- Editorial: evitar alegações pseudocientíficas ("elimina toxinas", "limpa o fígado", "derrete gordura").
- Comercial: ser usado como base de evidência para conteúdo, e-books e produtos do BemMaisBella.
