# CARTILHA DE ACOMPANHAMENTO — DIETA 30 DIAS

*Para colocar na porta da geladeira. Marcar todos os dias. Sem comparar com ninguém — só com você de ontem.*

---

## COMO USAR

1. Imprima em A5 (meia folha A4)
2. Cole na porta da geladeira
3. Marque todos os dias: ✓ (fez) / ✗ (não fez) / ~ (fez parcialmente)
4. Analise semanalmente — veja padrões, não dias isolados
5. Ajuste conforme você — flexibilidade é a regra

## REGRAS DA CARTILHA (baseado na pesquisa Think Olga 2023)

- **Não compare com outras pessoas** — só com você de ontem
- **✗ não é fracasso** — é informação
- **~ é progresso** — fez parcialmente, já é algo
- **✓ é celebração** — mas não precisa ser perfeito todos os dias
- **Ajuste conforme você** — cada mulher tem seu ritmo

---

## FLEXIBILIDADE (exemplos)

- Se não der para fazer a refeição completa → faça o que der (~)
- Se não der para fazer nada → marque ✗ sem culpa
- Se fizer 3 dias seguidos ✓ → aumente variedade
- Se 3 dias seguidos ✗ → veja se é cansaço, dentição, temperatura — ajuste
- Se alergia → pare, consulte pediatra, registre
