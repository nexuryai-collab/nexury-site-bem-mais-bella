# Bem Mais Bella

As instruções deste projeto estão em **[AGENTS.md](./AGENTS.md)** — arquivo único, lido também pelo Hermes, pelo Cursor e pelo Codex.

Leia-o antes de mexer em qualquer coisa. Três coisas que valem sempre:

1. Tudo é assinado só por **Lillith Nogah**. Nunca "Nexus", nunca "Fellipe Lelis".
2. **Número só com fonte.** Se não dá para conferir, a frase vai sem o número.
3. **Nada é publicado sem o Fellipe pedir.**
